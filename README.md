## Free learning resources

### YouTube courses and channels

| Resource | Best for | Use it when |
|---|---|---|
| [Bootlin](https://www.youtube.com/@Bootlin) | Embedded Linux, boot flow, kernel, device drivers and build systems | You are ready to move beyond bare-metal microcontrollers into Linux-based embedded systems. |
| [Embedded C programming playlist](https://www.youtube.com/watch?v=9wqvDPfjGvo&list=PLUQpHm_JtukKo2fvS9d8hqc7n1dgAyXBN&pp=0gcJCZAGa94AFGB0) | Embedded-C programming practice | You know basic C syntax and want to connect it to embedded concepts. |
| [The Linux Foundation](https://www.youtube.com/@LinuxfoundationOrg) | Linux ecosystem and foundational open-source learning | You want broader Linux context alongside embedded-Linux learning. |
| [Basics of Embedded Systems playlist](https://www.youtube.com/watch?v=nccWuB5ypxI&list=PLcbIZiT62e1gNZ-VWPO3rpTpXkHBMZa2n) | Embedded-systems fundamentals | You are starting with the basic vocabulary, architecture, and purpose of embedded systems. |

### Suggested order

1. Start with the **Basics of Embedded Systems** playlist.
2. Learn C, then work through the **Embedded C programming** playlist.
3. Move to microcontrollers, peripherals, protocols, and RTOS through the roadmap.
4. Use **Bootlin** and **The Linux Foundation** resources when you begin embedded Linux.
